Напишите короткие ответы в README.md проекта. Важно своими словами, не копировать документацию:

1. Перечислите фазы Event Loop в правильном порядке. На какой фазе выполняются setTimeout колбэки, а на какой — setImmediate?

Ответ: синхронные функции - nexxtTick - microtask - macrotask. SetTimeout -- macrotask, setImmediate -- microtask (check())

2. Почему process.nextTick выполняется раньше, чем Promise.then? К какой категории (microtasks/macrotasks) они относятся?

Ответ: Потому что nextTick имеет приоритет. Он не относится к микро/макро таскам. Promise.then -- микротаска

3. Что произойдёт, если в обработчике роута Fastify сделать синхронный тяжёлый цикл? Как это влияет на другие запросы?

Ответ: весь сервер будет ждать результата обработки, другие запросы будут недоступны.

4. В чём разница между CommonJS (require) и ESM (import)? Как "type": "module" в package.json меняет поведение?

Ответ: разные виды импортов: require (более новый) vs import (более старый). От import постепенно уходят. + в CommonJS не поддерживается верхнеуровневый await.

5. Объясните принцип REST своими словами. Почему PUT /api/products/5 — это обновление, а POST /api/products — создание?

Ответ: Принцип REST -- набор правил, который объясняет, как приложения (или клиент-сервер) могут общаться друг с другом. PUT может быть чем угодно, это зависит от того, как программист  описал код для метода. Но тогда это уже будет отход от правил rest api. По стандартам -- put - полное обновление, либо создание при отсутствии объекта.

6. Что такое graceful shutdown и почему fastify.close() важнее, чем просто убить процесс?

Ответ: Если убиить процесс, сервер может не завершить свои операции (например, запись в бд). При корректном завершении через fastify.close() сервер перестанет принимать новые соединения, завершит все фоновые операции и будет остановлен с освобождением ресурсов.
